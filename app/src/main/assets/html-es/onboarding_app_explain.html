¡Bienvenido a Mi Ritmo Digital! Esta aplicación ha sido desarrollada para el Estudio Harvard sobre el Uso del Teléfono y nos permitirá registrar el uso de tu teléfono.

Más específicamente, la aplicación recopilará la siguiente información de tu teléfono:

  • Uso general del teléfono
  • Uso de aplicaciones específicas
  • Nivel de batería
  • Tiempo que tu teléfono ha estado encendido
  • Versiones de hardware y software del teléfono

Para reiterar, tus datos se mantendrán privados y se almacenarán de forma segura.
